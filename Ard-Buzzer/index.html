Il buzzer passivo

Modifica la frequenza, ascolta il suono e osserva come cambia il segnale generato da Arduino con tone().

Segnale sul pin D8

Ampiezza: 0–5 V nominaliDuty cycle: 50%

Codice Arduino

const int buzzer = 8;

void setup() {
  pinMode(buzzer, OUTPUT);
  tone(buzzer, 440);
}

void loop() {
}

tone(buzzer, 440) genera un'onda quadra alla frequenza selezionata, finché non viene interrotta con noTone(buzzer).

La frequenza cambia l'altezza del suono, mentre il duty cycle rimane al 50%. Puoi selezionare una nota direttamente sulla scala o spostarti liberamente tra due note.

Periodo: T = 1 / f
Con f in Hz, T = 1000 / f in millisecondi.

Simulazione per Arduino UNO / Nano classico. Note in temperamento equabile (La4 = 440 Hz), frequenze arrotondate all'intero per tone(). Il suono del browser è un'onda quadra sintetica a volume ridotto: un buzzer reale può avere timbro e intensità differenti.
