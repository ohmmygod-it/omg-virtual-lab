Come funziona la conversione?

Arduino confronta la tensione letta su A0 con la propria tensione di riferimento. Con una risoluzione di 10 bit può restituire 1024 codici interi (da 0 a 1023).

05 Sketch completo · dal potenziometro ai volt

Questo è il programma da caricare su Arduino UNO R3 o Nano classico. Ogni passaggio ha una variabile e una spiegazione: prima si legge il numero digitale, poi si calcola quanto vale un livello, infine si ricava una stima della tensione.

/*
   OMG VIRTUAL LAB - ANALOGREAD E CONVERSIONE ADC
   Schede: Arduino UNO R3 / Nano classico (ADC a 10 bit)

   COLLEGAMENTI DEL POTENZIOMETRO DA 10 kΩ:
   - Un terminale esterno    → 5V di Arduino
   - Terminale centrale      → A0 di Arduino
   - Altro terminale esterno → GND di Arduino

   Ruotando il potenziometro varia la tensione su A0.
   analogRead() NON restituisce volt: restituisce un intero.
*/

// 1) DICHIARIAMO LE COSTANTI CHE USEREMO
const byte PIN_POTENZIOMETRO = A0;  // ingresso analogico
const float VREF = 5.0;           // riferimento nominale in volt
const int LIVELLI_ADC = 1024;           // 10 bit: 2^10 = 1024 livelli
const int CODICE_MASSIMO = LIVELLI_ADC - 1; // l'ultimo codice è 1023

void setup() {
  Serial.begin(9600);            // avviamo il Monitor Seriale
  analogReference(DEFAULT);      // su UNO: riferimento = Vcc
}

void loop() {
  // 2) LEGGIAMO LA TENSIONE PRESENTE SUL PIN A0
  // L'hardware ADC la converte in un codice intero: 0...1023.
  int codiceADC = analogRead(PIN_POTENZIOMETRO);

  // 3) CALCOLIAMO QUANTI VOLT VALE UN LIVELLO
  // VREF = 5 V; livelli = 1024.
  // 5,0 / 1024 = 0,0048828125 volt = circa 4,88 mV.
  float voltPerLivello = VREF / LIVELLI_ADC;

  // 4) RICAVIAMO UNA STIMA DELLA TENSIONE SU A0
  // Esempio: 512 * 0,0048828125 = 2,500 V.
  // È una stima quantizzata, NON una misura infinitamente precisa.
  float tensioneVolt = codiceADC * voltPerLivello;

  // 5) FACOLTATIVO: ESPRIMIAMO LA LETTURA IN PERCENTUALE
  // Qui dividiamo per 1023 perché è il CODICE MASSIMO.
  // Questo NON cambia il numero di livelli, che resta 1024.
  float percentuale = codiceADC * 100.0 / CODICE_MASSIMO;

  // 6) MOSTRIAMO LE TRE INFORMAZIONI SUL MONITOR SERIALE
  Serial.print("Codice ADC: ");
  Serial.print(codiceADC);
  Serial.print(" / 1023  |  Tensione stimata: ");
  Serial.print(tensioneVolt, 3);  // 3 cifre dopo la virgola
  Serial.print(" V  |  Posizione: ");
  Serial.print(percentuale, 1);  // 1 cifra decimale
  Serial.println(" %");

  delay(200);                    // una lettura ogni 0,2 secondi
}

Perché 1024 in una formula e 1023 nell'altra? Con 10 bit esistono 1024 intervalli, numerati da 0 a 1023. Per calcolare l'ampiezza di un intervallo usiamo VREF / 1024; per esprimere il codice come percentuale del valore digitale massimo usiamo codice / 1023. Non sono due risoluzioni diverse.

Nota sul riferimento: nel codice VREF = 5.0 è un valore nominale. Su UNO R3/Nano classico DEFAULT usa la tensione di alimentazione come riferimento; se la scheda riceve 4,85 V, la conversione in volt con 5,0 V non è esatta. Inoltre 5,0 V in ingresso produce il codice 1023, mentre 1023 × 5 / 1024 ≈ 4,995 V: quest'ultimo è il limite inferiore dell'intervallo dell'ultimo codice, non la tensione fisica esatta.

Modello didattico: Arduino UNO R3 / Nano con ATmega328P e riferimento ADC predefinito nominale di 5 V. La conversione usa 1024 intervalli, con saturazione al codice 1023; la modalità sinusoidale distingue segnale continuo, campionamento e valore mantenuto fra due letture. I grafici non rappresentano un'uscita fisica del pin. Schede Arduino diverse possono avere altre risoluzioni o riferimenti. Riferimento Arduino: Analog Input Pins.
