Come funziona? analogWrite(pin, valore) usa valori da 0 a 255. A parità di periodo, aumentando il duty cycle aumenta la frazione di tempo in cui il pin è HIGH. Per esempio, 128 ≈ 50%. L'occhio integra i lampeggiamenti rapidi e percepisce una luminosità media.

05 / Dal simulatore al banco

Sketch Arduino d'esempio

Questo sketch imposta il LED sui valori iniziali mostrati nel simulatore. Per cambiarli durante l'esecuzione, inserisci altri valori in analogWrite() o usa tre potenziometri con analogRead() e map().

// LED RGB a catodo comune: 220 Ω in serie a ogni colore
const int pinRosso = 9;
const int pinVerde = 10;
const int pinBlu   = 11;

void setup() {
  pinMode(pinRosso, OUTPUT);
  pinMode(pinVerde, OUTPUT);
  pinMode(pinBlu, OUTPUT);
}

void loop() {
  // PWM: 0 = spento, 255 = acceso al massimo
  analogWrite(pinRosso, 255);
  analogWrite(pinVerde, 70);
  analogWrite(pinBlu,   45);
}
